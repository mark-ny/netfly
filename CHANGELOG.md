# Changelog

Versions are documentation labels for upgrade batches. Verification status for each is in NETFLY_UPGRADE_REPORT.md.

## 1.6.0 (untested: no package install, browser or Postgres was available)
- Viewer profiles: "Who's watching?" picker at `/who`, up to 5 profiles per account, create/rename/colour/delete, profile switcher in the header; list, history and ratings are kept per profile
- TV series: `/series` and `/series/:slug` with seasons, episode list and progress bars; the player offers the next episode with a cancellable 8 second countdown; admin tabs for Series and Episodes
- Episodes are ordinary films linked through `episodes`, so `tools/ingest.py`, uploads and playback are unchanged
- New migration `supabase/migrations/20261126090000_profiles_series.sql` (NOT applied; changes the primary keys of watchlists, watch_progress and ratings, so deploy it together with this client)
- Neon draft: `neon/002_profiles_series.sql` generated by `neon/translate_migration.py`
- Worker: account export now includes viewer profiles (the Worker is otherwise unchanged)
- Tests added, not run: 15 database policy cases in `tests/db.mjs`, 2 Playwright cases
- Not built on purpose: kids profiles, PIN lock, maturity limits (see NETFLY_RECOMMENDATIONS.md)
